

## Store and Display Pattern Insights History

### The Problem
- Pattern insights are generated by the AI but only stored in React component state
- Navigating away loses all generated insights -- users must re-generate (costs AI credits, wastes time)
- The edge function analyzes the **last 30 dreams** (with their analyses), but users have no visibility into this

### Solution

Create a `pattern_insights` table to persist every generation, and load the most recent one automatically when visiting the Patterns page.

### Database Changes

New table: `pattern_insights`

| Column | Type | Notes |
|---|---|---|
| id | uuid | Primary key |
| user_id | uuid | NOT NULL |
| recurring_themes | jsonb | Array of theme strings |
| emotional_patterns | text | Paragraph of emotional analysis |
| suggestions | jsonb | Array of suggestion strings |
| dreams_analyzed | integer | How many dreams were included |
| created_at | timestamptz | DEFAULT now() |

RLS policies:
- SELECT: `auth.uid() = user_id`
- INSERT: `auth.uid() = user_id`

### Edge Function Changes (`dream-patterns/index.ts`)

After generating patterns from the AI, save them to `pattern_insights` before returning:

```text
// After parsing AI response
await serviceClient.from("pattern_insights").insert({
  user_id: user.id,
  recurring_themes: patterns.recurring_themes,
  emotional_patterns: patterns.emotional_patterns,
  suggestions: patterns.suggestions,
  dreams_analyzed: dreams.length,
});
```

### Frontend Changes (`src/pages/Patterns.tsx`)

1. On page load, fetch the most recent `pattern_insights` row for the user and display it immediately (no "Generate Insights" needed on first visit if insights exist)
2. Show metadata: "Based on X dreams -- Generated on [date]"
3. "Generate Insights" button still works but now saves new results, replacing the displayed insights
4. Add a subtle note near the button: "Analyzes your last 30 dreams"

### User Experience After Fix

1. User visits Patterns page for the first time with 5+ dreams -- sees "Generate Insights" button
2. User clicks it -- AI generates patterns, they're saved to the database and displayed
3. User navigates away, comes back -- insights are loaded from the database automatically
4. User records more dreams, comes back -- can click "Generate Insights" again to get fresh analysis
5. The page shows "Based on 30 dreams -- Generated Feb 19, 2026" so users know the scope

### Technical Details

- No changes to the existing `analyses` or `dreams` tables
- The `pattern_insights` table only stores the structured output (themes, emotions, suggestions) plus metadata
- Old insights are kept (could add a history view later) but only the latest is displayed by default
- RLS ensures users can only see their own insights
